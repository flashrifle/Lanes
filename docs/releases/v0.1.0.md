## Lanes 0.1.0 — 첫 공개 버전

IDE 수준의 Git 로그를 담은 macOS용 독립 실행형 Git 클라이언트입니다. 무료·오픈소스(Apache-2.0).

### 히스토리
- 레인 배치와 Bek 정렬의 커밋 그래프(IntelliJ Platform 오픈소스 그래프 엔진 기반), 지하철 노선도 스타일, 브랜치마다 하나의 노선 색
- 노선 클릭으로 브랜치 줄기 강조, 브랜치 비교, reflog
- 텍스트·해시·브랜치·사용자·날짜·경로 필터
- 파일 히스토리(이름 변경 추적), blame, 선택한 줄 히스토리
- 좌우 비교 diff 창(단어 단위 하이라이트)

### 작업
- 커밋하지 않은 변경 보기, 파일·hunk·줄 단위 스테이징, 커밋·amend·Undo Commit
- push(미리 보기, upstream 설정, force-with-lease만 허용), stash
- merge·rebase(진행 상태, Continue/Skip/Abort, 충돌 해결), cherry-pick, revert, reset, 태그
- 페치·풀·푸시 버튼에 받을/보낼 커밋 수 표시

### 메뉴 막대
- 저장소별 상태와 풀·푸시·페치, 빠른 커밋 창, 창을 닫아도 메뉴 막대에 상주, 백그라운드 페치(선택)

### 그 밖에
- 한국어 / English, 설정 창, 자동 업데이트, 이슈 보고
- 텔레메트리 없음

### 설치
- `Lanes_0.1.0_universal.dmg`를 열어 응용 프로그램 폴더로 옮기세요 (Apple Silicon·Intel, Apple 공증).
- 또는 `brew install --cask flashrifle/tap/lanes`

요구 사항: macOS 11 이상, git 2.23 이상.

JetBrains, IntelliJ, WebStorm은 JetBrains s.r.o.의 상표입니다. Lanes는 JetBrains와 관련이 없는 독립 프로젝트입니다.
